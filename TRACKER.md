# Standalone NCAA tracker

Approved Nov 23, 2026. A navigation aid for trained agents; no player statistics extraction, no SportsDataverse runtime dependency, no historical backfill, no changes to the professional Mega Board.

## Current windows and archive
FBS/FCS: Thursday through Wednesday, rollover Thursday 3 AM Eastern. Men's/women's basketball: yesterday, today and tomorrow, rollover daily 3 AM Eastern. Unresolved tracked games survive rollover. Source requests use proven single-day scoreboard queries; truncated responses fail without overwriting prior state. Multi-day range requests returned HTTP 400 in staging and are not used. Completed games archive immediately independent of links. First-run archive start is the actual Eastern calendar date; subsequent runs reuse it. Old dates fetched solely for previously tracked pending games cannot import new historical records. A failed source fetch leaves the prior durable feed intact. The feed is atomically written; git history on ncaa-data retains prior versions.

## Link hierarchy and optional discovery
Every game gets NCAA division scoreboard navigation, and school schedules/homepages when unambiguously mapped. Standard schedule paths are navigation shortcuts, not verified game report destinations. Individual reviewed Game Center, online box score and PDF box score/gamebook links can be added independently. Prefer home school, then away; keep existing links. Missing optional links are not failures. The timing engine targets hourly pregame Game Center eligibility; after final first observed, 5 minutes for hour one, 15 minutes for the next three hours, hourly until 24 hours total, then no further enrichment. Persist final_seen_at and last slots; archive rollover doesn't cancel the window. Actual times may vary with scheduler delay. Reviewed sources only: reviewed_game_links.json contains independently reviewed observations, with kind, sport, date, school, both team names and scores for final reports, URL and reviewed=true. PDFs require a reviewed official school parent URL. Exact ESPN ID is preferred; same-day ambiguities without ID are rejected. No guessed game IDs or blocked-access retries. The automatic acquisition pilot is limited to four explicitly configured women's basketball sources; other school sources and report types remain reviewed-only. School schedule and NCAA navigation remain fully useful; no routine manual submissions required. The Ohio State/Michigan Game Center observation is a current upcoming example, not a backfill.

## Preview
Run from root:
```sh
python tracker.py --output preview/feed.json
cp site/index.html site/app.js site/style.css preview/
python -m http.server 8000 --directory preview
```
Current and archive filters are separate; sport dropdowns retain expanded state and contain full instructions even when no games are present. Browser polls the feed once per minute; upstream updates target every five minutes after activation.

## Activate standalone Pages
Repo Settings > Pages > Build and deployment > Source: GitHub Actions. Then Actions > NCAA tracker update and publish > Run workflow on main. Verify first successful update and deployment, check live URL and data branch. Once verified, Settings > Secrets and variables > Actions > Variables > New repository variable: NCAA_TRACKER_ENABLED=true. This enables the five-minute scheduled workflow (GitHub may delay runs). The workflow serializes updates, loads prior ncaa-data/feed.json, persists new data before Pages publish, and never commits to main. Manual runs work without the schedule variable. No pre-merge workflow writes production data. If first activation fails, investigate; do not enable recurring execution before the cause is resolved. No paid services.

## Automatic PDF discovery pilot
For tracked women's basketball games involving Vanderbilt, Iowa, Virginia Tech or Miami (FL), the producer checks the school’s public schedule (after checking robots rules), matches the exact opponent, date, and score, follows the explicitly published document wrapper to the school’s CDN, and verifies the actual first PDF page for the final box score marker, date, sport and both named final scores. PDFs are not stored or rehosted; only a verified URL and source metadata are saved. At most three distinct explicitly configured schools per run, one eligible game per school, no repeated attempts within a slot, no retries on access denial or rate limiting; optional source state persists in ncaa-data, and a blocked school stays disabled until reviewed without disabling unrelated schools. The pilot ends at the existing 24-hour cutoff and never changes scores, archive membership or previous report URLs. PDF tools are installed only when a pilot game is eligible. Temporary optional source or dependency errors are logged without blocking ordinary game updates. Online box score candidates and Game Center automation are not yet enabled; no unconfigured school or other sport is searched automatically. The original manual reviewed link paths remain available. Live pre-merge control is read-only and never writes production data.

## WBB source expansion
Iowa publishes direct CDN PDF links; Virginia Tech publishes a document wrapper and short W/L score format; Miami publishes a Gamebook document wrapper. Only explicit school domains and observed school CDN bucket prefixes are allowed. The official first-page final/date/sport/team-score check remains mandatory. No inferred paths, no arbitrary CDN buckets, no historical backfill or automatic extraction of player statistics. School-level access denials persist independently, and legacy global block/slot state is preserved. The WMT provider's own terms restrict scraping its site/platforms; use only public official school pages and observed public document links with robots checks, not WMT APIs, private endpoints, or any blocked path. Public accessibility alone is not a blanket contractual permission; review any school-specific terms or provider notice before enabling further sources. Live controls run only in the expansion PR and do not write production data.
